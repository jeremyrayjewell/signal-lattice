# Credits

## Visual inspiration: E.C.H. (Eiichi Ishii)

Every scene in this project began as an independent study of a specific
artwork from the **dailycoding** series by **E.C.H. / Eiichi Ishii**
([OpenProcessing @u277028](https://openprocessing.org/@u277028)). Those
originals are licensed **CC BY-NC-SA** by their creator.

This project does not copy, fork, or redistribute that source code. For each
referenced piece, a scene here was built by visually studying a screenshot or
description of the original, writing down its observed compositional grammar
(silhouette, primitive shapes, layering, palette behavior, motion, etc.), and
then independently implementing a new p5.js sketch that explores the same
visual relationships with original code, original parameters, and (where
audio-reactive) original mappings to the accompanying track. No source
functions, exact random seeds, or implementation logic from the originals are
reused — only the visual relationships they establish.

The full evidence trail — URLs, license labels as observed on each work's
page, visual-grammar notes, and what was independently reinterpreted — is
recorded per scene in [docs/source-references.md](docs/source-references.md).
Per-scene build notes, including what each scene changed relative to its
source study, live in the matching `docs/prototype-NN-study.md` file.

Because the reference material is CC BY-NC-SA, any reproduction, adaptation,
or non-commercial reuse you make of this project should carry attribution
back to E.C.H. for the visual lineage, in addition to whatever credit this
repository's own [LICENSE](LICENSE) requires for the code itself.
